# Grade Claro TV RJ

Grade de programação da Claro TV para **Barra Mansa, Rio de Janeiro**, publicada como site estático e atualizada automaticamente.

🔗 **Acesse a grade:** https://epitaciosouza.github.io/grade-claro-tv-rj/

## Conteúdo

- Programação organizada por canal e horário
- Grade localizada para Barra Mansa-RJ
- Identificação dos canais com programação de São Paulo quando aplicável
- Área dedicada a esportes ao vivo
- Consulta rápida diretamente pelo navegador
- Layout responsivo para computador e celular

## Esportes ao vivo

A área **Esportes ao vivo** apresenta somente eventos confirmados, com competição e confronto identificados.

Não são classificados como eventos ao vivo:

- Reprises e videotapes
- Programas de notícias
- Mesas-redondas e debates
- Aquecimentos e pré-jogos
- Programas de estúdio
- Conteúdos promocionais

## Atualização automática

O repositório possui um fluxo automatizado que:

1. Coleta novamente os dados das fontes oficiais.
2. Valida o arquivo gerado.
3. Publica uma nova versão no GitHub Pages.
4. Mantém a última versão válida no ar quando a fonte está indisponível ou a validação falha.

A atualização automática é executada a cada três dias.

## Fontes e confiabilidade

A grade utiliza apenas informações oficiais confirmadas. Dados ausentes ou não confirmados não são inventados nem apresentados como definitivos.

A programação pode sofrer alterações pelas emissoras ou pela operadora sem aviso prévio.

## Como utilizar

1. Acesse o site pelo link acima.
2. Localize o canal desejado.
3. Consulte os horários e programas exibidos.
4. Verifique a área **Esportes ao vivo** para partidas e competições confirmadas.
